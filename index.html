給 AI 的指令

製作一個能做 1 加到 N 的 Fortran 程式並完成編譯，確認可以執行計算並輸出結果。（414210780 方柏崴）

答題過程

指揮 AI 安裝 GNU Fortran 編譯器（gfortran 13.3.0），撰寫 sum.f90：讀入 N，檢查 N 為正整數，用 do 迴圈從 1 累加到 N 後輸出。變數使用 64 位元整數，避免大數溢位。

program sum_1_to_n
  implicit none
  integer(kind=8) :: n, i, total

  write(*, '(A)', advance='no') 'Enter N: '
  read(*, *) n

  if (n < 1) then
    write(*, '(A)') 'Error: N must be a positive integer.'
    stop 1
  end if

  total = 0
  do i = 1, n
    total = total + i
  end do

  write(*, '(A, I0, A, I0)') 'Sum of 1 to ', n, ' = ', total
end program sum_1_to_n

編譯與執行結果

$ gfortran -Wall -o sum sum.f90
== 編譯成功 ==（無任何警告）
$ echo 100 | ./sum
Enter N: Sum of 1 to 100 = 5050

答案

編譯成功，N = 100 時輸出 5050，與公式 N(N+1)/2 = 5050 相符。

答題過程

指揮 AI 用 shuf 在 1～1,000,000 之間隨機抽出三個 N，輸入程式執行，並將輸出與公式 N(N+1)/2 自動比對。

for k in 1 2 3; do
  n=$(shuf -i 1-1000000 -n 1)
  got=$(echo $n | ./sum | awk -F'= ' '{print $2}')
  exp=$(( n*(n+1)/2 ))
  [ "$got" = "$exp" ] && echo PASS || echo FAIL
done

program sum_1_to_n                     ! 宣告主程式，名稱為 sum_1_to_n
  implicit none                        ! 關閉隱式型別宣告，所有變數都必須明確宣告
  integer(kind=8) :: n, i, total       ! 宣告 64 位元整數：n 為上限、i 為迴圈計數器、total 為累加總和

  write(*, '(A)', advance='no') 'Enter N: '   ! 輸出提示文字，游標停在同一行等待輸入
  read(*, *) n                         ! 從標準輸入讀取使用者輸入的 N

  if (n < 1) then                      ! 檢查 N 是否小於 1（不合法的輸入）
    write(*, '(A)') 'Error: N must be a positive integer.'  ! 輸出錯誤訊息
    stop 1                             ! 以錯誤碼 1 結束程式
  end if                               ! 結束 if 判斷區塊

  total = 0                            ! 將累加總和初始化為 0
  do i = 1, n                          ! 迴圈：i 從 1 跑到 n
    total = total + i                  ! 將目前的 i 加到總和中
  end do                               ! 結束 do 迴圈

  write(*, '(A, I0, A, I0)') 'Sum of 1 to ', n, ' = ', total  ! 輸出結果，I0 表示以最小寬度輸出整數
end program sum_1_to_n                 ! 結束主程式
